The five meta-paths in Table I organize these relations
into complementary service contexts. The serving-based U–
S–U path aggregates users attached to the same MEC, expos-
ing established contention. The visibility-based U–S–U path
connects users with common satellite alternatives, exposing
demand that may converge on the same server after subsequent
decisions. This distinction retains both the current sharing
structure and the opportunities through which that structure
can change. The remaining paths incorporate neighboring de-
mand, overlapping satellite coverage, and ISL neighborhoods.

features and propagates messages successively along its con-
stituent relations.
