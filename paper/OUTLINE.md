# HAN–PDQN 论文大纲

## I. Introduction（引言）

说明研究背景、问题动机、现有工作的不足及本文贡献。

### A. Background and Motivation

- 介绍 LEO 卫星边缘计算的应用背景及终端计算资源限制。
- 说明卫星运动、可见性变化和多用户资源竞争对服务的影响。
- 解释卫星选择与部分任务卸载为什么需要联合决策。

### B. Related Work and Research Gap

- 卫星切换与图学习：已有工作如何表达网络关系并辅助卫星选择。
- 卫星计算卸载：已有工作如何处理部分卸载、共享资源和动态任务。
- 混合动作强化学习：已有工作如何联合处理离散选择与连续控制。
- 明确本文研究缺口：竞争关系如何同时影响各候选卫星的卸载比例及其选择价值。

### C. Main Contributions

- 联合卫星选择与部分卸载的序贯决策建模。
- 区分已有资源竞争和潜在竞争的异质图关系表示。
- 利用同一关系表示进行卸载比例生成和卫星–比例价值评估的 HAN–PDQN 控制框架。

章末用一段文字介绍论文组织，无需单独设置小节。沿用现有引言主体，后续压缩重复的方法介绍，突出研究缺口与贡献。

## II. System Model（系统模型）

保留现稿已有的四个小节，统一描述环境、任务和服务过程。本章配置系统场景图，并统一后续使用的符号与假设。

### A. Network Model

- 用户、卫星、时隙和本地/MEC 计算架构。
- 卫星可见集合、剩余可见时间及决策前后的服务关联。

### B. Communication Model

- 上行接入批次与带宽共享。
- 信道增益、上下行速率及传播时延。
- 任务接纳时的链路快照及通信成本计算口径。

### C. Task and Computation Model

- 随机任务到达、任务属性、用户 FIFO 队列及连续卸载比例。
- 本地处理器排队执行和 MEC 有限队列、并发处理与资源共享。
- 本地与远端分支并行执行的任务时延。
- 终端计算与上行传输能耗。
- 任务成功、超时、断连终止和评估结束时待完成任务的区别。

### D. Handover and Service Model

- 切换触发条件、候选卫星可行性和动作掩码。
- 迁移容量检查、残余任务迁移及目标队列重新排队。
- 切换失败、断连、重连及固定服务中断开销。

## III. Problem Formulation（问题定义）

采用紧凑的独立章节，不再设置 A/B/C 小节。目标篇幅为 IEEE 双栏版式约 1–1.5 栏，原则上不超过一个双栏整页；这是本稿的写作目标，不是 TMC 的统一规定。

正文按以下顺序连续展开：

1. **决策变量。** 简要定义卫星动作和对应的连续卸载请求，沿用第二章的关联、任务及资源符号；实际关联与卸载比例由第二章的迁移、接纳及本地回退规则确定，不重复展开执行流程。
2. **长期目标。** 用紧凑的服务效用统一任务成功与失败、成功任务时延和终端能耗、服务中断与切换代价；如保留共享负载均衡项，明确其物理含义。目标应与实际奖励的优化方向对应，不单独优化忽略失败任务的成功任务平均时延。
3. **统一优化问题。** 集中写出 P1 及编号约束 C_1、C_2、……，覆盖离散选择、连续比例、切换触发、目标链路、迁移容量和 MEC 资源约束。区分请求时的可行性检查与提交后的实际容量；不把任务截止时间写成所有任务必然满足的硬保证。
4. **约束解释与难点。** 用一段解释各组约束，再用短段指出混合变量、多用户竞争和跨时隙队列/迁移耦合，引出 HAN–PDQN。没有证明时不宣称 NP-hard，也不声称传统优化方法均不可用。

完整状态/观测、参数化动作空间、转移过程、奖励发放时刻、归一化细节、动作掩码和联合执行顺序移至第四章相应小节。第三章不插入算法图，不展开网络结构或训练流程。

## V. Performance Evaluation（性能评估）

本轮正文依据 `paper/` 已有四张数值结果图组织为以下四个小节，按实验设置 → 训练及参数表现 → 任务性能 → 服务与运行代价展开。每组图依次说明主要观察、关键基线的定量比较及与系统模型对应的解释。保留后续实验计划，但不把没有对应结果的主题单列为本轮正文小节。

### A. Experimental Setup and Evaluation Protocol

- 用两张紧凑参数表给出系统配置和算法/训练设置；任务类别、概率和参数分布在正文补充。
- 以保存的实验配置为准：66 星、6 个轨道面、550 km、53°，20–40 用户；本地处理率 1 Gcycle/s，MEC 两核总处理率 10 Gcycle/s。
- 定义 HAN+MAPPO、MAPPO、MADDPG、PDQN、Min-Distance、Full-Local 六个对比方法；Min-Distance 采用固定全卸载请求，受相同可行性与本地回退规则约束。
- 明确实际超参数：HAN+PDQN 的 replay batch size 为 512，无 HAN 的 PDQN 为 128；不把二者描述为除 HAN 以外完全相同的控制变量实验。
- MADDPG 使用其训练历史中实际保存的 actor/critic 学习率 1e-4/3e-4、batch size 128 和目标软更新系数 0.005；不能用通用配置中的其他算法默认字段替代。
- 说明 150k 交互预算、512 步回合、训练种子 42–46、每种子 5 回合评估，以及按平均评估回报选择模型的规则；按实际协议表述，不引入未实施的独立测试集划分。
- 模型选择的周期评估间隔按实际运行交代：HAN+PDQN、PDQN、两种 MAPPO 为 25k 环境步，MADDPG 为 10 回合。
- 各种子先汇总其评估回合，再计算五种子均值和 95% bootstrap 置信区间。指标沿用第二章定义。

### B. Training Convergence and Hyperparameter Sensitivity

- 先插入单栏 `algorithm_convergence_u30.pdf`，比较五种学习方法在 30 用户时的训练变化和后期回报；说明主方法后期平均回报较高，不把前期上升速度笼统写成最快。
- 再插入单栏 `convergence_u30.pdf`，保留上下两个子图，分别讨论 PDQN 学习率和 replay batch size；这属于超参数敏感性，不属于带宽/算力等系统资源敏感性。
- 学习率 3e-3、batch size 256 的平均表现及种子间不确定性应据图讨论；1e-3、512 是表现良好的默认设置，不宣称唯一最优或 batch size 越大越好。

## VI. Conclusion（结论）

- 使用两段紧凑正文，约 160–220 个英文单词，不设置小节，不新增公式、图表或文献综述。
- 第一段概括联合切换与部分卸载问题，并突出核心设计：HAN 区分已有与潜在竞争，同一关系表示同时条件化 PDQN 的候选卸载比例及卫星–比例价值评估。
- 第二段概括五训练种子、20–40 用户的已验证结果；相对 PDQN 的成功任务时延、截止时间违约率及每成功任务能耗降低 2.16%、21.26%、5.72%，与第五章汇总口径一致。服务中断、总能耗和切换代价以简短定性结论补充，避免重复全部数字。
- 末句提出具体后续方向：扩展通信与计算资源联合分配，并研究跨星座、跨业务配置的策略迁移；不把这些方向写成已完成结果，不另列局限清单。
- 对比结论针对完整方法及实际评估配置，不将全部改善单独归因于 HAN；不新增最优性、理论收敛或未见场景泛化主张。
